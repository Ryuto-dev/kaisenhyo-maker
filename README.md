# 音響回線表メーカー

音響卓（ミキサー）用の**回線表 / 入力表**をブラウザで作り、**A4 PDF** で保存できる静的サイトです。
ビルド不要・登録不要・オフラインで動作します。

## 使い方

1. **公演情報**を入力（タイトル・会場・日付・作成者・Rev・備考）
2. **INPUT（入力）** と **OUTPUT（出力）** を、それぞれ専用の表に入力
   - INPUT 列: No. / 回線名 / マイク・機器 / 種別 / +48V / スタンド / 卓CH / BOX / CBL / 長さ / 備考
   - OUTPUT 列: No. / 出力名 / 卓OUT / 接続先 / BOX / CBL / 長さ / 備考
   - 行を追加すると、直前の行の卓CH・BOX を自動で +1（例: `SB1-8` → `SB1-9`、`AUX1` → `AUX2`）、種別・ケーブル・長さは引き継ぎ
3. **プレビュー**で A4 の仕上がりを確認
4. **PDFで保存** → 印刷ダイアログの保存先で「PDFに保存」を選択

## プロ現場向けの編集機能

| 操作 | 内容 |
| --- | --- |
| `Enter` / `Shift+Enter` / `↑↓` | 上下のセルへ移動（最終行で Enter → 行を追加） |
| `⌘/Ctrl + Enter` | 下に行を挿入 |
| `⌘/Ctrl + D` | 行を複製 |
| `⌘/Ctrl + Shift + ⌫` | 行を削除 |
| `Alt + ↑↓` / `⋮⋮` ドラッグ | 行の並べ替え（同じセクション内） |
| 行右端の `⋯` | 上下に挿入・見出し挿入・複製・移動・削除 |
| 貼り付け | Excel / Google スプレッドシートの範囲を選択セルから展開 |
| `⌘/Ctrl + Z` / `⇧⌘Z` | 元に戻す / やり直す（削除や並べ替えも戻せます） |

- **重複チェック** — 同じセクション内で卓CH・BOX が重複すると赤く表示し、見出しに件数を出します
- **+48V** はワンクリックで切り替え、PDF には「48V」と印字
- 列の表示は INPUT / OUTPUT で個別に切り替え可能（スタンド列は初期状態で非表示）

## 機材ピックリスト（A4 別ページ・チェック欄つき）

搬出・搬入・バラシ・帰庫の各工程で、印刷した紙にチェックを書き込んで**機材の紛失・積み忘れを防ぐ**ためのリストです。
回線表とは別の A4 ページとして印刷されます。

- **回線表から作成** — INPUT / OUTPUT のマイク・機器（`UR4D + SM58` のような「+」区切りは分割）、スタンド、ケーブル（種類 × 長さ）、ステージボックスを自動で集計
- 卓・電源・電池などの追加機材は、行を足して自由に記入（列: No. / 品名 / 型番・仕様 / 数量 / 予備 / ケース / 備考）
- **チェック欄（工程）** は自由に設定できます（初期値: `出庫, 搬入, バラシ, 帰庫`／カンマ区切り・最大 6 つ）
- 印刷内容:
  - 工程ごとのサイン欄（日時・担当・確認）
  - 各行に工程ごとのチェックボックス。数量が 2 以上の行には「/6」のように持ち出し総数（数量＋予備）を薄く印字し、数えた数を書き込めます
  - 注意事項と「不足・破損・追加メモ」欄
  - ページ番号は回線表とは別に「PICK LIST 1 / 2」と表示
- **印刷する内容**（用紙・表示設定）: 回線表＋ピックリスト／回線表のみ／ピックリストのみ
- ピックリスト欄の「ピックリストを印刷」またはメニューから、設定に関係なく**ピックリストだけ**を印刷できます

## PDF

- A4 縦・横、文字サイズ 小・中・大
- INPUT → OUTPUT の順に、それぞれ専用の列見出しで印刷（「OUTPUT は新しいページから」も選べます）
- ページをまたぐ場合は列見出しと「（続き）」を自動で付け、見出し行だけがページ末尾に残らないよう調整
- 備考が入りきらない場合は次のページへ送り、ページ番号は実際のページ数と一致します

## データ

- 入力内容はブラウザ（localStorage）に自動保存
- JSON 書き出し・読み込み（バックアップ / 別 PC へ移動）、CSV 書き出し（Excel 用 BOM 付き・セクション別）
- 旧形式（1 つの表に IN/OUT が混在していたデータ）は、読み込み時に自動で INPUT / OUTPUT に振り分けられます

## ローカルで開く

```sh
cd kaisenhyo-maker
python3 -m http.server 4173
# → http://localhost:4173
```

`index.html` を直接ダブルクリックしても動きますが、ブラウザによっては保存領域が制限されるため、
ローカルサーバー経由での利用をおすすめします。

## 公開する

`index.html` / `styles.css` / `app.js` の 3 ファイルをそのまま置くだけです（ビルドなし）。

- **GitHub Pages**: リポジトリに push → Settings → Pages → ブランチを指定
- **Netlify / Vercel**: ドラッグ＆ドロップ、またはリポジトリを接続（フレームワーク未使用）

## データについて

入力内容は**お使いのブラウザ内（localStorage）にのみ**保存され、外部へ送信されません。
別の端末やバックアップには「⋯ → JSONで書き出す」を使ってください。

## ファイル構成

```
index.html   画面の構造（ヘッダー＋公演情報＋設定＋編集テーブル＋プレビュー）
styles.css   画面デザイン + A4印刷用CSS（@page / 印刷時レイアウト）
app.js       状態管理（INPUT/OUTPUT 別）・表の編集・重複チェック・A4ページ分割・PDF出力
```
