# 音響回線表メーカー

音響卓（ミキサー）用の**回線表 / 入力表**をブラウザで作り、**A4 PDF** で保存できる静的サイトです。
ビルド不要・登録不要・オフラインで動作します。

## 使い方

1. **公演情報**を入力（タイトル・会場・日付・作成者・Rev・備考）
2. **回線表**に回線を入力
   - `Enter` … 同じ列の次の行へ移動（最終行なら新しい行を追加）
   - `Alt + ↑ / ↓` … 行を上下に移動
   - 左端の `⋮⋮` をドラッグ … 行の並べ替え
   - `＋ 見出し` で「ドラムス」「ボーカル」などのセクション行を挿入
3. **プレビュー**で A4 の仕上がりを確認
4. **PDFで保存** → 印刷ダイアログの保存先で「PDFに保存」を選択

用紙は A4 縦／横、文字サイズは 3 段階、印刷する列は個別にオン／オフできます。
回線が多くて 2 ページ以上になっても、ページごとに表のヘッダー行とページ番号が入り、
プレビューと PDF のページ割りはそのまま一致します。

## 機能

- 入力内容の自動保存（ブラウザの localStorage）
- サンプルひな形（バンド編成 22 IN + 10 OUT / 講演・セミナー 10 回線）
- **入力（INPUT）・出力（OUTPUT）の両セクション** — 行ごとに IN/OUT を切り替え可能。出力では列ラベルが「機器→接続先」「卓CH→卓OUT」に変わります
- A4 縦・横、文字サイズ 小・中・大
- 列の表示切り替え（機器・種別・BOX・CBL・長さ・備考）
- ページ割りプレビュー（ページ番号・2 ページ目以降の見出し付き）
- 元に戻す / やり直す（`⌘Z` / `⇧⌘Z`、Windows は `Ctrl+Z`）
- JSON 書き出し・読み込み（バックアップ／別の PC への移動）
- CSV 書き出し（Excel 用 BOM 付き）

## ローカルで開く

```sh
cd kaisenhyo-maker
python3 -m http.server 4173
# → http://localhost:4173
```

`index.html` を直接ダブルクリックしても動きますが、ブラウザによっては保存領域が制限されるため、
ローカルサーバー経由での利用をおすすめします。

## 公開する

`index.html` / `styles.css` / `app.js` の 3 ファイルをそのまま置くだけです（ビルドなし）。

- **GitHub Pages**: リポジトリに push → Settings → Pages → ブランチを指定
- **Netlify / Vercel**: ドラッグ＆ドロップ、またはリポジトリを接続（フレームワーク未使用）

## データについて

入力内容は**お使いのブラウザ内（localStorage）にのみ**保存され、外部へ送信されません。
別の端末やバックアップには「⋯ → JSONで書き出す」を使ってください。

## ファイル構成

```
index.html   画面の構造（ヘッダー＋公演情報＋設定＋編集テーブル＋プレビュー）
styles.css   画面デザイン + A4印刷用CSS（@page / 印刷時レイアウト）
app.js       状態管理・表の編集（入力/出力セクション対応）・A4ページ分割・PDF出力
```
