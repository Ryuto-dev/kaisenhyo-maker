# 機材準備.com

現場の準備を、ひとつのプロジェクトに。
**音響の回線表**と**照明の仕込み図**を同じプロジェクトで管理し、そのまま **PDF** にできる静的サイトです。
ビルド不要・登録不要・オフラインで動作し、データはお使いのブラウザ内に保存されます。

## できること

### プロジェクト

- 公演・現場ごとにプロジェクトを作成（プロジェクト名・会場・日付・作成者・Rev・メモ）
- 1 つのプロジェクトに「回線表」と「照明仕込み図」を並べて持てる
- ホームで作成・再開・設定変更・複製・JSON 書き出し・削除
- 書き出したプロジェクトファイルを読み込んで復元（別 PC への移動やバックアップ）
- 変更は自動保存。ヘッダーに保存状態を表示

### 回線表（AUDIO）

音響卓まわりの INPUT / OUTPUT を、現場で使える表に整理します。

- INPUT 列: No. / 回線名 / マイク・機器 / 種別 / +48V / スタンド / 卓CH / BOX / CBL / 長さ / 備考
- OUTPUT 列: No. / 出力名 / 卓OUT / 接続先 / BOX / CBL / 長さ / 備考
- 行を追加すると、直前の行の卓CH・BOX を自動で +1（例: `SB1-8` → `SB1-9`、`AUX1` → `AUX2`）
- セル移動・行の挿入/複製/削除/並べ替え、Excel からの範囲貼り付け
- 卓CH・BOX の重複を赤く表示
- サンプル（バンド / トーク）から雛形を作成
- **機材ピックリスト** — 回線表からマイク・スタンド・ケーブル・BOX を自動集計し、工程ごとのチェック欄・サイン欄つきで A4 別ページに印刷
- A4 縦・横、文字サイズ 小・中・大でプレビュー → PDF 保存
- JSON / CSV の書き出し・読み込み

### 照明仕込み図（LIGHTING）

会場の灯体配置を mm 単位で作図し、現場用の仕込み図にします。

- 無限キャンバス。ホイールでズーム、Space / 中ボタンドラッグでパン
- グリッドとスナップ（500mm / 1m / 2m）
- 標準灯体ライブラリ（PAR / フレネル / スポット / ムービング / LED バー / LED ウォッシュ / ブリンダー / ストロボ / フォロースポット / フット）
- 灯体ごとの属性: ユニット番号・回路・DMX ユニバース / アドレス・色・ゴボ・用途・消費電力・高さ・向き・ビーム角・吊り物・メモ
- 吊り物（バトン / トラス / スタンド）を線で作図。近くに置いた灯体は自動で吊り物に載る
- テキスト・矩形の作図、会場図面の下敷き画像（差し替え・不透明度変更）
- 灯体表をその場で編集。ユニット番号の自動振り直し、複製、削除
- ラベルは灯体・吊り物・ほかのラベルと重ならない位置に自動配置
- 凡例・タイトルブロック・縮尺・ビーム表示の切り替え
- 元に戻す / やり直し、キーボード操作、サンプル配置
- A3 / A4、横 / 縦、1:20〜1:200 でプレビュー → PDF 保存
- SVG / PNG / 灯体リスト CSV の書き出し

## 使い方

1. ホームで **新しいプロジェクト** を作る（または既存のプロジェクトを開く）
2. 使う道具を選ぶ — **回線表** か **照明仕込み図**
3. 入力・作図する（自動保存されます）
4. **プレビュー** で仕上がりを確認し、**PDFで保存** → 印刷ダイアログで「PDFに保存」

プロジェクトの設定（名前・会場・日付・作成者・Rev）は、回線表と仕込み図の両方に反映されます。

## 回線表の編集機能

| 操作 | 内容 |
| --- | --- |
| `Enter` / `Shift+Enter` / `↑↓` | 上下のセルへ移動（最終行で Enter → 行を追加） |
| `⌘/Ctrl + Enter` | 下に行を挿入 |
| `⌘/Ctrl + D` | 行を複製 |
| `⌘/Ctrl + Shift + ⌫` | 行を削除 |
| `Alt + ↑↓` / `⋮⋮` ドラッグ | 行の並べ替え（同じセクション内） |
| 行右端の `⋯` | 上下に挿入・見出し挿入・複製・移動・削除 |
| 貼り付け | Excel / Google スプレッドシートの範囲を選択セルから展開 |
| `⌘/Ctrl + Z` / `⇧⌘Z` | 元に戻す / やり直す（削除や並べ替えも戻せます） |

- **重複チェック** — 同じセクション内で卓CH・BOX が重複すると赤く表示し、見出しに件数を出します
- **+48V** はワンクリックで切り替え、PDF には「48V」と印字
- 列の表示は INPUT / OUTPUT / ピックリストで個別に切り替え可能（スタンド列は初期状態で非表示）

## 機材ピックリスト（A4 別ページ・チェック欄つき）

搬出・搬入・バラシ・帰庫の各工程で、印刷した紙にチェックを書き込んで**機材の紛失・積み忘れを防ぐ**ためのリストです。
回線表とは別の A4 ページとして印刷されます。

- **回線表から作成** — INPUT / OUTPUT のマイク・機器（`UR4D + SM58` のような「+」区切りは分割）、スタンド、ケーブル（種類 × 長さ）、ステージボックスを自動で集計
- 卓・電源・電池などの追加機材は、行を足して自由に記入（列: No. / 品名 / 型番・仕様 / 数量 / 予備 / ケース / 備考）
- **チェック欄（工程）** は自由に設定できます（初期値: `出庫, 搬入, バラシ, 帰庫`／カンマ区切り・最大 6 つ）
- 印刷内容:
  - 工程ごとのサイン欄（日時・担当・確認）
  - 各行に工程ごとのチェックボックス。数量が 2 以上の行には「/6」のように持ち出し総数（数量＋予備）を薄く印字し、数えた数を書き込めます
  - 注意事項と「不足・破損・追加メモ」欄
  - ページ番号は回線表とは別に「PICK LIST 1 / 2」と表示
- **印刷する内容**（用紙・表示設定）: 回線表＋ピックリスト／回線表のみ／ピックリストのみ
- ピックリスト欄の「ピックリストを印刷」またはメニューから、設定に関係なく**ピックリストだけ**を印刷できます

## データ

- 保存先はブラウザの **localStorage**（キー: `kizai-junbi.com/projects/v1`）
- 外部への送信はありません。同じブラウザ・同じ端末でのみ開けます
- 別の端末やバックアップには、ホームの **書き出し** でプロジェクト JSON を保存してください
- 旧「音響回線表メーカー」の保存データ（`kaisenhyo-maker/v1`）は、初回起動時にプロジェクトへ自動移行されます
- 下敷き画像はプロジェクト内に埋め込みます。大きな画像を何枚も入れると保存容量に注意してください

## ローカルで開く

```sh
cd kizai-junbi
python3 -m http.server 4173
# → http://localhost:4173
```

`index.html` を直接ダブルクリックしても動きますが、ブラウザによっては保存領域が制限されるため、
ローカルサーバー経由での利用をおすすめします。

## 公開する

ビルドは不要です。リポジトリの中身をそのまま静的サイトとして置いてください。

- **GitHub Pages**: リポジトリに push → Settings → Pages → ブランチを指定
- **Netlify / Vercel**: ドラッグ＆ドロップ、またはリポジトリを接続（フレームワーク未使用）

## ファイル構成

```
index.html          画面の構造（ホーム / 回線表 / 仕込み図 / ダイアログ）
css/
  app.css           共通 UI・ホーム・回線表・A4 印刷用 CSS
  lighting.css      照明仕込み図のエディタ・プレビュー・印刷用 CSS
js/
  util.js           共通ユーティリティ（DOM・保存・ダウンロードなど）
  store.js          プロジェクトのスキーマ・保存・移行・書き出し/読み込み
  audio.js          回線表エディタ
  lighting.js       照明仕込み図エディタ
  home.js           ホーム / プロジェクト管理
  app.js            ルーター・ヘッダー・メニュー
docs/
  照明仕込み図 仕様書.md
```

スクリプトはビルドせず、`util.js` → `store.js` → `audio.js` → `lighting.js` → `home.js` → `app.js` の順で読み込みます。

## 動作環境

- 最新の Chrome / Edge / Safari / Firefox
- キーボードショートカットは macOS の ⌘、Windows では Ctrl を使います
- 印刷はブラウザの印刷機能を使用します（PDF 保存も印刷ダイアログから）
